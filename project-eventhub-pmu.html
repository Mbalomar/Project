EventHub PMU

A campus events listing and RSVP system used by student clubs to publicize activities.

About this project

EventHub allowed clubs across PMU to post events, manage RSVPs, and send reminder emails to attendees. Built with vanilla JavaScript and a lightweight Express backend, it served as an early demonstration of dynamic content rendering without a frontend framework.
