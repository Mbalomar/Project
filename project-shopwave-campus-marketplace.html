ShopWave — Campus Marketplace

A peer-to-peer e-commerce marketplace for PMU students to buy and sell textbooks, electronics, and dorm essentials.

About this project

ShopWave is a full-stack e-commerce platform built for the Building E-Commerce course. It features product listings with image galleries, category browsing, a shopping cart, order checkout flow, seller dashboards, and an admin panel for moderating listings. The team implemented JWT-based authentication, Stripe test-mode payments, and a responsive UI built with React and Tailwind CSS, backed by a Node.js/Express API and PostgreSQL database.
