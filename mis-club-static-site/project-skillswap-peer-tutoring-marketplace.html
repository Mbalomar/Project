SkillSwap — Peer Tutoring Marketplace

A platform connecting students who want to teach and learn skills from one another, with built-in scheduling.

About this project

SkillSwap matches students offering tutoring in one subject with students seeking help in another, using a credit-based exchange system instead of cash. Features include profile ratings, calendar-based session booking, and in-app messaging. Built with Next.js, Prisma, and SQLite.
