BookNest — Online Bookstore

A responsive online bookstore with a recommendation engine and wishlist functionality.

About this project

BookNest is a full e-commerce bookstore featuring catalog search and filtering, a recommendation engine based on browsing history, wishlists, and a secure checkout flow. Built with Django and PostgreSQL, it demonstrates server-side rendering, session-based auth, and payment gateway integration.
