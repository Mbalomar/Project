InvenTrack — Smart Inventory Manager

A real-time inventory and warehouse tracking dashboard with low-stock alerts and supplier management.

About this project

InvenTrack helps small businesses track stock levels across multiple warehouses, set automatic reorder thresholds, and manage supplier relationships. Built with Vue.js and Firebase for real-time sync, the project demonstrates dynamic dashboards with live charts, CSV import/export, and role-based permissions for staff vs. managers.
