ClinicFlow — Appointment & Records System

A clinic management system for scheduling appointments, managing patient records, and generating billing reports.

About this project

ClinicFlow digitizes front-desk operations for small clinics: patient intake, appointment scheduling with conflict detection, electronic medical record notes, and automated invoice generation. Built with PHP and MySQL, the system enforces role-based access (receptionist, doctor, admin) and includes input validation and audit logging for HIPAA-style compliance awareness.
